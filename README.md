# بات گزارش قیمت طلا، دلار و نقره در کانال تلگرام

این بات هر چند دقیقه یک‌بار (پیش‌فرض: هر ۵ دقیقه) قیمت طلا، دلار، یورو، نقره، سکه و ... را
از سایت [tgju.org](https://www.tgju.org) می‌خواند و به‌صورت یک پیام فرمت‌شده در کانال تلگرام شما پست می‌کند.

---

## ۱) ساخت بات در تلگرام

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بفرستید.
3. یک اسم و یک یوزرنیم (باید به `bot` ختم شود، مثلاً `GoldPriceIR_bot`) برای بات انتخاب کنید.
4. BotFather یک **توکن** به شما می‌دهد، شبیه:
   `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`
   این توکن را جایی امن نگه دارید (به کسی ندهید).

## ۲) اضافه کردن بات به کانال

1. کانال تلگرامی خودتان را با ز کنید (اگر ندارید، بسازید).
2. به بخش **Administrators** کانال بروید و بات ساخته‌شده را به‌عنوان **ادمین** اضافه کنید
   (حداقل با دسترسی "Post Messages").
3. اگر کانال شما **پابلیک** است، آیدی آن همان یوزرنیم است، مثلاً: `@my_gold_channel`
4. اگر کانال شما **پرایوت** است، باید آیدی عددی کانال را پیدا کنید (با `-100` شروع می‌شود).
   ساده‌ترین راه: یک پیام در کانال فوروارد کنید به بات [@userinfobot](https://t.me/userinfobot)
   یا [@JsonDumpBot](https://t.me/JsonDumpBot) تا آیدی چت را به شما نشان دهد.

## ۳) تنظیم فایل config.py

فایل `config.py` را باز کنید و مقادیر زیر را جایگزین کنید:

```python
BOT_TOKEN = "123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
CHANNEL_ID = "@my_gold_channel"   # یا آیدی عددی مثل -1001234567890
POST_INTERVAL_SECONDS = 300      # هر ۵ دقیقه (می‌توانید به 600 برای هر ۱۰ دقیقه تغییر دهید)
```

می‌توانید به‌جای ویرایش فایل، این مقادیر را به‌صورت متغیر محیطی (Environment Variable) هم ست کنید.

اگر خواستید آیتم‌های دیگری (مثل پوند، درهم، دلار کانادا و ...) هم اضافه کنید، به دیکشنری
`ITEMS` در همان فایل مراجعه کنید — کلید باید همان متنی باشد که در سایت tgju.org دیده می‌شود.

## ۴) اجرای دائمی و رایگان بدون سرور — با GitHub Actions (روش پیشنهادی)

اگر سرور (VPS) ندارید، نیازی هم نیست بخرید. با **GitHub Actions** می‌توانید همین
پروژه را کاملاً رایگان و بدون نگهداری، هر ۵ دقیقه یک‌بار خودکار اجرا کنید.
از آنجا که ران‌رهای GitHub Actions روی سرورهای مایکروسافت و خارج از ایران اجرا
می‌شوند، فیلتر بودن تلگرام در ایران هیچ مشکلی برای این روش ایجاد نمی‌کند (فقط
برای ساخت اولیه‌ی بات با BotFather در اپ تلگرام خودتان به فیلترشکن نیاز دارید).

### گام ۱: ساخت یک ریپوی گیت‌هاب
1. وارد [github.com](https://github.com) شوید و یک ریپوی جدید بسازید (می‌تواند **Private** باشد
   تا کد و اسرارتان عمومی نباشد؛ توکن بات را هرگز مستقیم داخل کد قرار نمی‌دهیم، پس این نکته صرفاً برای احتیاط بیشتر است).
2. تمام فایل‌های این پروژه (شامل پوشه‌ی `.github/workflows/`) را در آن ریپو آپلود/پوش کنید:

```bash
git init
git add .
git commit -m "Gold price telegram bot"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

(اگر با گیت راحت نیستید، می‌توانید از دکمه‌ی "Add file > Upload files" در همان صفحه‌ی گیت‌هاب هم استفاده کنید.)

### گام ۲: تنظیم Secrets (توکن و آیدی کانال)
توکن بات و آیدی کانال را **داخل کد قرار ندهید** — آن‌ها را به‌عنوان "Secret" در گیت‌هاب ذخیره کنید:

1. در صفحه‌ی ریپو بروید به: **Settings → Secrets and variables → Actions → New repository secret**
2. یک Secret با نام `BOT_TOKEN` بسازید و توکنی که از BotFather گرفتید را در آن بگذارید.
3. یک Secret دیگر با نام `CHANNEL_ID` بسازید (مثلاً `@my_gold_channel` یا آیدی عددی کانال).

### گام ۳: فعال‌سازی و تست
1. به تب **Actions** ریپو بروید. اگر پیام تأیید اجرای Workflow را دید، آن را فعال کنید (Enable).
2. روی ورک‌فلوی «Post Gold/Currency Prices to Telegram» کلیک کنید و از دکمه‌ی **Run workflow**
   (اجرای دستی) استفاده کنید تا بلافاصله یک‌بار تست شود.
3. اگر لاگ اجرا سبز شد (✅) و پیام در کانالتان ظاهر شد، یعنی همه‌چیز درست است.
4. از این به بعد، طبق تنظیم `cron: "*/5 * * * *"` هر ۵ دقیقه خودکار اجرا می‌شود — نیازی به
   هیچ کار دیگری از طرف شما نیست، حتی لازم نیست سیستم‌تان روشن باشد.

### نکات مربوط به GitHub Actions
- حساب‌های رایگان گیت‌هاب معمولاً چند هزار دقیقه اجرای رایگان در ماه دارند که برای این کار
  (چند ثانیه اجرا هر ۵ دقیقه) کاملاً کافی است.
- زمان‌بندی `cron` در GitHub Actions «تضمین‌شده» به‌معنای دقیقه‌به‌دقیقه نیست؛ در ساعات شلوغ
  ممکن است اجرا چند دقیقه دیرتر انجام شود. اگر این تأخیر برایتان مهم است، می‌توانید فاصله را
  به ۱۰ یا ۱۵ دقیقه تغییر دهید (در فایل `.github/workflows/post-prices.yml`، مقدار
  `*/5 * * * *` را به `*/15 * * * *` تغییر دهید).
- اگر بعداً ریپو را Public کردید، مطمئن شوید توکن هیچ‌وقت داخل کد commit نشده (فقط داخل Secrets است).
- ورک‌فلو باید اجازه‌ی نوشتن روی ریپو (`permissions: contents: write`) داشته باشد؛ این تنظیم از
  قبل در `post-prices.yml` انجام شده، ولی اگر در تنظیمات سازمانی/ریپوی شما دسترسی پیش‌فرض Actions
  محدود به Read-only باشد، باید در **Settings → Actions → General → Workflow permissions** گزینه‌ی
  **Read and write permissions** را فعال کنید، وگرنه مرحله‌ی کامیت کردن `last_message.json` با خطا مواجه می‌شود.

## ویرایش پیام به‌جای ارسال پیام جدید

به‌جای این‌که هر بار یک پیام تازه در کانال پست شود، بات همان یک پیام را نگه می‌دارد و در هر
دور فقط محتوای آن را به‌روزرسانی (ویرایش/Edit) می‌کند؛ کانال شما شلوغ نمی‌شود و همیشه یک پیام
(آخرین قیمت‌ها) در آن پین/موجود است. هر پیام تاریخ (روز هفته + `YYYY/MM/DD`) و ساعت را دقیقاً
**به وقت تهران** (`Asia/Tehran`) نشان می‌دهد، صرف‌نظر از این‌که خود سرور اجراکننده (مثلاً
GitHub Actions) با چه منطقه‌ی زمانی‌ای کار می‌کند.

نحوه‌ی کار:
- آیدی همان یک پیام در فایل `last_message.json` نگه داشته می‌شود.
- در حالت اجرای دائمی (`bot.py` روی VPS)، این مقدار در حافظه می‌ماند و مشکلی نیست.
- در حالت GitHub Actions (`post_once.py`)، چون هر اجرا روی ماشین تازه انجام می‌شود، ورک‌فلو
  بعد از هر اجرا خودش فایل `last_message.json` را دوباره commit/push می‌کند تا اجرای بعدی
  بداند کدام پیام را باید ویرایش کند.
- اگر ویرایش به هر دلیلی ممکن نباشد (مثلاً پیام قبلی حذف شده یا بیش از ۴۸ ساعت از ارسالش
  گذشته — محدودیت خود تلگرام برای ویرایش پیام)، بات به‌طور خودکار یک پیام جدید می‌فرستد و از
  آن به بعد همان پیام تازه را ویرایش می‌کند.
- اگر می‌خواهید همیشه یک پیام جدید بفرستد (رفتار قبلی)، کافی است قبل از هر اجرا فایل
  `last_message.json` را پاک/خالی (`{}`) کنید.

## ۵) روش جایگزین: اجرای بات روی سیستم شخصی (فقط برای تست)

```bash
pip install -r requirements.txt
python3 bot.py
```

اگر پیام "بات شروع به کار کرد..." را دیدید و بعد از چند ثانیه پیام قیمت‌ها در کانال ظاهر شد،
همه‌چیز درست کار می‌کند. برای توقف: `Ctrl+C`

⚠️ نکته مهم: اگر بات را فقط روی سیستم شخصی (ویندوز/مک) اجرا کنید، به‌محض خاموش کردن سیستم
یا بستن ترمینال، بات از کار می‌افتد. برای گزارش **دائمی و ۲۴ ساعته**، باید آن را روی یک
سرور (VPS) اجرا کنید — ادامه راهنما را ببینید.

## ۶) روش جایگزین دیگر: اجرای دائمی روی یک VPS لینوکسی (اگر بعداً سرور تهیه کردید)

### گام ۱: تهیه یک سرور
یک VPS ارزان با Ubuntu 22.04/24.04 کافی است (حتی ضعیف‌ترین پلن هم برای این کار کافیست).
چند گزینه رایج: Hetzner، Contabo، DigitalOcean، یا سرورهای داخلی مثل ArvanCloud / پارس‌پک
(برای دسترسی پایدار به تلگرام از داخل ایران معمولاً VPS خارج از ایران راحت‌تر است).

### گام ۲: اتصال و آماده‌سازی
```bash
ssh root@YOUR_SERVER_IP

apt update && apt install -y python3 python3-pip git
```

### گام ۳: انتقال فایل‌های پروژه
فایل‌های این پروژه (`bot.py`, `scraper.py`, `config.py`, `requirements.txt`) را روی سرور
در مسیر `/root/telegram_gold_bot` قرار دهید (مثلاً با `scp` از سیستم خودتان، یا آپلود روی
یک ریپوی گیت‌هاب خصوصی و `git clone` روی سرور).

```bash
mkdir -p /root/telegram_gold_bot
cd /root/telegram_gold_bot
# فایل‌ها را اینجا کپی کنید، سپس:
pip3 install -r requirements.txt
```

توکن و آیدی کانال را در `config.py` وارد کنید.

### گام ۴: اجرای دائمی با systemd (توصیه‌شده)
فایل `telegram-gold-bot.service` را در مسیر زیر کپی کنید:

```bash
cp telegram-gold-bot.service /etc/systemd/system/telegram-gold-bot.service
systemctl daemon-reload
systemctl enable telegram-gold-bot
systemctl start telegram-gold-bot
```

بررسی وضعیت و لاگ‌ها:
```bash
systemctl status telegram-gold-bot
journalctl -u telegram-gold-bot -f
```

با این روش، بات:
- بعد از ری‌استارت سرور خودکار اجرا می‌شود.
- اگر به هر دلیلی کرش کند، خودکار دوباره اجرا می‌شود (`Restart=always`).

### گزینه جایگزین: اجرا با Docker
اگر ترجیح می‌دهید از Docker استفاده کنید، بگویید تا یک Dockerfile هم برایتان آماده کنم.

## ۷) نکات مهم

- **اسکرپینگ چیست؟** چون منبع قیمت‌ها، خواندن مستقیم صفحه‌ی سایت tgju.org است (نه یک API رسمی)،
  اگر ساختار HTML سایت در آینده تغییر کند، ممکن است لازم شود فایل `scraper.py` به‌روزرسانی شود.
  پارسر طوری نوشته شده که تا حد امکان در برابر تغییرات جزئی مقاوم باشد، اما تغییرات بزرگ
  در طراحی سایت می‌تواند نیاز به اصلاح داشته باشد.
- برای اطمینان از سالم بودن استخراج قیمت‌ها، می‌توانید مستقیماً فایل `scraper.py` را جدا اجرا کنید:
  ```bash
  python3 scraper.py
  ```
  این دستور قیمت‌های استخراج‌شده را در ترمینال چاپ می‌کند (بدون ارسال به تلگرام).
- فاصله‌ی زمانی پیشنهادی برای پست در کانال حداقل ۵ دقیقه است؛ ارسال خیلی مکرر هم فشار
  زیادی روی سایت مبدأ می‌گذارد و هم ممکن است با محدودیت نرخ ارسال پیام تلگرام مواجه شوید.
- توکن بات را هرگز در جایی عمومی (مثل یک ریپوی گیت‌هاب پابلیک) قرار ندهید.
